RLinf Contribution Certificates

RLinf 开源社区贡献者证书 · Issued 2026.11.16

This page lists the certificates issued to RLinf community members who contributed to RLinf. Three tiers are currently issued: Reviewer (designated domain reviewers) and Recognized Contributor (sustained contributions across domains), and Candidate Area Owner (domain owner candidates).

本页列出 RLinf 开源社区贡献者证书。当前发放三个层级：评审者 Reviewer（指定领域评审）、认可贡献者 Recognized Contributor（多领域持续贡献）与 候选领域负责人 Candidate Area Owner（领域负责人候选）。按姓名或 GitHub ID 找到自己，点击 Open 查看证书，点击 Save HTML 下载原始文件（在浏览器中打开后可按 Ctrl/Cmd + P 另存为一页 PDF）。

Certificate ID format: RL2026 + tier digit + 3-digit sequence — tier 2 = Recognized Contributor, tier 3 = Reviewer, tier 4 = Candidate Area Owner. / 证书编号规则：RL2026 + 类型位（2 = 认可贡献者，3 = 评审者，4 = 候选领域负责人）+ 三位序号。
